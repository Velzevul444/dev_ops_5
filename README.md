# Практическая работа №5 — DevOps

Тема: Удалённый сервер и безопасный доступ. SSH, sudo, UFW, DNS.

## Окружение
- Ubuntu Server 26.04.1 LTS ARM64
- Oracle VirtualBox
- macOS
- IP: 192.168.56.2
- SSH: порт 2222
- Пользователь: devops

## Выполнено
- Создан пользователь devops с правами sudo.
- Настроена SSH-аутентификация по ключу.
- Отключён вход по паролю и запрещён вход root.
- Настроен UFW: LIMIT 2222, ALLOW 80 и 443.
- Настроено локальное доменное имя.

## Аудит
Запуск на сервере:

sudo bash scripts/audit.sh
